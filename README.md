## 🌍 Real Forex vs. OTC Market Mechanics

The bot distinguishes between **Real Interbank Forex** and **Broker OTC (Over-The-Counter)** instruments:

```mermaid
flowchart LR
    Asset["Selected Asset Symbol"] --> Check{"Ends with _otc?"}
    Check -->|No (e.g. EURUSD)| Real["Real Interbank Forex"]
    Check -->|Yes (e.g. EURUSD_otc)| OTC["Broker OTC Synthetic"]

    Real --> Hours{"Within Sun 22:00 - Fri 22:00 UTC?"}
    Hours -->|Yes| SessionCheck{"Check Session & Overlap"}
    Hours -->|No| BlockMarket["Block Trading (Market Closed)"]

    OTC --> OTC247["24/7 Continuous Trading (Broker Algorithm)"]
```

### Key Differences:

1. **Market Hours Enforcement:**
   - **Real Forex (`EURUSD`, `GBPUSD`, `USDJPY`):** Strictly tradeable from **Sunday 22:00 UTC to Friday 22:00 UTC**. Any signals outside these hours are suppressed.
   - **OTC (`EURUSD_otc`, etc.):** Tradeable 24/7/365, generated by Quotex's internal matching engine.

2. **Session Liquidity Awareness:**
   - **Asia / Pacific (21:00 – 06:00 UTC):** Low volatility, wider spreads. Suppressed for real forex unless `ALLOW_LOW_LIQUIDITY=True`.
   - **London Session (07:00 – 16:00 UTC):** High institutional liquidity and clean trend continuation.
   - **New York Session (12:00 – 21:00 UTC):** High volume driven by US macroeconomic data.
   - **London-NY Overlap (12:00 – 16:00 UTC):** Peak market liquidity. Prioritized when `PREFER_SESSION_OVERLAP=True`.

3. **Payout Structure:**
   - Real Forex pairs typically offer lower payouts (**70% – 80%**, observed ~77%), raising the break-even win rate to **56.5%**.
   - OTC pairs typically offer higher advertised payouts (**80% – 92%**, observed ~85%), requiring a **54.1%** break-even win rate.

## 🔬 Empirical Real-Data Validation Findings

In contrast to synthetic Geometric Brownian Motion (GBM) simulations which artificially manufacture positive win rates, this codebase was validated on **43,196 real 1-minute historical candles** from Quotex:

| Metric | Empirical Out-Of-Sample Result | Break-Even Hurdle | Status |
|---|---|---|---|
| **Walk-Forward Accuracy** | **50.2% – 50.4%** | **56.50%** (at 77% payout) | ❌ Below Hurdle |
| **Precision** | **50.5%** | > 56.5% | ❌ Below Hurdle |
| **Mean Expected Value (EV)** | **-8.83% to -8.98%** | $\ge +2.0\%$ | ❌ Negative Expectancy |
| **Filter Trade Pass Count** | **0 Trades** | N/A | ✅ Risk Gate Protected |

### The Mathematical Reality of Binary Options:
Because binary options payouts are asymmetric:
- Winning trade returns: $+Payout \times Stake$ (e.g., $+0.77 \times 1.0 = +0.77$)
- Losing trade forfeits: $-1.0 \times Stake$ ($-1.00$)

The **Break-Even Win Rate ($W_{be}$)** is:
$$W_{be} = \frac{1}{1 + Payout} = \frac{1}{1 + 0.77} \approx 56.50\%$$

At a near-random-walk real market accuracy of **50.2%**, the Expected Value is:
$$EV = (0.502 \times 0.77) - (0.498 \times 1.0) = 0.38654 - 0.49800 = -11.15\%$$

**Conclusion:** Financial markets on 1-minute bars closely resemble weak-form efficient random walks. Overcoming a 7.5 to 11.5 percentage point broker hurdle on binary options is mathematically improbable without severe overfitting. **The bot's EV filter correctly identified this negative expectancy and refused to place trades, protecting the practice balance.**

## 🔄 Transferability: "What Actually Works"

While binary options cannot overcome broker payout asymmetry, **this codebase's architecture is directly transferable to symmetric payout markets**:

1. **Spot Forex & Futures Trading:**
   - On Spot Forex or CME Micro Futures, risk/reward is symmetric ($1:1$) or favorable ($1:2$ or $1:3$ with trailing stops).
   - In symmetric markets with tight ECN spreads (0.2–0.5 pips), a model achieving **52.0% – 53.5% directional accuracy** yields substantial compounding alpha and Sharpe ratios above 1.5.

2. **Perpetual Crypto Futures (Binance / Bybit / Hyperliquid):**
   - Exchange fees are 0.02%–0.05% (maker/taker) rather than a 23% broker haircut.
   - The same feature engine (multi-timeframe RSI, MACD, Bollinger Bands, ATR regime detection) can generate entry/exit signals for trailing-stop strategies.

3. **Options Spreads (Equity Options):**
   - Credit spreads and debit spreads with defined risk and favorable probability of profit.

## 🛠️ CLI Installation & Setup

### 1. Requirements
- Python 3.10+ (tested on Python 3.10 through 3.14)
- Google Chrome or Chromium

```bash
git clone <repository-url>
cd Quotex-bot
python -m venv venv

# Windows
.\venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

### 2. Configuration (`.env`)
Copy `.env.example` to `.env` and fill in your details:
```ini
DEMO_ONLY=True
QUOTEX_EMAIL=your_email_here
QUOTEX_PASSWORD=your_password_here
SIGNAL_CONFIDENCE_THRESHOLD=0.60
MIN_EXPECTED_VALUE=0.01
```

### 3. CLI Operational Modes

```bash
# Launch Streamlit Browser UI
streamlit run app.py

# Standalone Model Training (e.g. 30 days history on 1m timeframe)
python main.py --train --asset EURUSD_otc --days 30 --timeframe 1m

# Historical Walk-Forward Backtest
python main.py --backtest --asset EURUSD_otc --days 30 --timeframe 1m --export logs/backtest_trades.csv

# Live Signal Streaming (Safe, alert-only mode)
python main.py --mode signal

# Assisted Trade Execution (Demo account only, requires confirmation phrase)
python main.py --mode assisted
```

### 4. Running Automated Tests
```bash
python -m pytest tests/ -v
```
Verifies UI rendering, feature leakage integrity, EV mathematical formulations, and risk circuit breakers.
